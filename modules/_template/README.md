# Module template

Copy this checklist into a new module proposal before writing product code.

- Module ID, name, product line, and semantic version
- Exact Zenodo DOI, Git commit, Lean module, and Aristotle receipt
- Input schema, units, assumptions, bounds, and missing-data behavior
- Deterministic `compute(inputs)` kernel
- Output schema, uncertainty, refusal conditions, and human-review triggers
- Kernel tests plus full preview and certify/verify tests
- Empirical-validation status and non-claims
- Rights and data-provenance statement

New modules begin `BLOCKED`. Publication or a clean Lean proof alone does not
make the adapter certification-ready.
